Language, playback & file format

Write instructions from left to right and finish by executing B. Cells are signed, arbitrary-precision integers, initially zero. The pointer can move in either direction. Input and output use ASCII (0–127); values do not wrap. F# and G must be paired, including nested loops. Stop cancels a running program; Cancel in the input prompt does the same.

After a successful halt, the whole written score plays once, including any notes after B. Loop repetitions do not extend the audio. Every instruction sounds in octave 4, lasts 0.15 seconds, and has a 0.02-second attack and release. E# becomes F; B# becomes C.

A .sym file is a JSON array of {"x":112,"y":250,"pitch":"C","isSharp":false} objects. Coordinates are logical canvas pixels; pitch is the natural letter at that Y position. Save downloads program.sym. Load validates the entire file before replacing your score. Everything runs locally, including audio and file handling.
